Dossier des photos du carrousel « Galerie » de la page d'accueil.

- Déposez ici vos images (.jpg .jpeg .png .webp .gif .avif) : elles apparaissent
  automatiquement dans le carrousel, sans rebuild ni redémarrage.
- Retirez un fichier : il disparaît du carrousel.
- Ordre d'affichage = ordre alphanumérique des noms (ex. 01, 02, 10).
  Astuce : préfixez par un numéro (01-…, 02-…) pour maîtriser l'ordre.
- Les fichiers cachés (commençant par un point) et ce README sont ignorés.

En production, ce dossier se trouve sur le conteneur : /opt/cazalia/web/gallery
